
## 🚀 Tech Stack

- **Backend**: Python (FastAPI), Node.js (NestJS)
- **AI**: Google Gemini API, LangGraph / CrewAI
- **Voice**: AgentLine, VoiceAgent, Whisper, ElevenLabs
- **CRM**: DeskcommCRM, OpenCloser
- **Data**: PostgreSQL + pgvector, Redis, MinIO (S3), ClickHouse
- **Frontend**: React / Next.js
- **Deployment**: Docker, Kubernetes

# فروش‌یار ۳۶۰ 🤖💼

**فروش‌یار ۳۶۰** یک سیستم یکپارچه، self-hosted و متن‌باز فروش و پشتیبانی مبتنی بر هوش مصنوعی است که مانند یک تیم کامل از فروشندگان، پشتیبان‌ها و اپراتورهای تلفن، ۲۴ ساعته در تمام پلتفرم‌های پیام‌رسان فعالیت می‌کند.

## ✨ ویژگی‌های کلیدی

- **🧠 مغز متفکر (Google Gemini)**: تشخیص نیّت، تشخیص زبان، ترجمه، تحلیل احساسات و تولید پاسخ با Gemini 2.0 Flash و Gemini 1.5 Pro.
- **🌐 پشتیبانی چندکاناله**: اینستاگرام، تلگرام، تیک‌تاک، فیس‌بوک، واتساپ، بله، روبیکا، وب‌چت، SMS، ایمیل و تلفن.
- **📞 دروازه صوتی**: تماس ورودی و خروجی، IVR، تبدیل گفتار به متن و برعکس، رونویسی زنده و تحلیل احساسات.
- **💳 درگاه‌های پرداخت چندگانه**:
  - 🇮🇷 درگاه‌های داخلی: زرین‌پال، آیدی‌پی، نکست‌پی
  - 🌍 درگاه‌های بین‌المللی: Stripe، PayPal
  - ₿ درگاه‌های کریپتو: NOWPayments، Cryptomus، CryptAPI
- **🗂️ CRM اختصاصی**: مدیریت مخاطبین، سرنخ‌ها، معاملات، قیف فروش، اینباکس، تیکت‌ها، تراکنش‌ها و گزارش‌گیری کامل.
- **🔐 کنترل دسترسی مبتنی بر نقش (RBAC)**: نقش‌های ادمین، مدیر، اپراتور و کاربر با مجوزهای دقیق.
- **📊 مدیریت محصولات و قیمت‌گذاری**: قیمت‌گذاری متمرکز، تاریخچه قیمت و پشتیبانی از چند ارز.
- **🌍 پشتیبانی چندزبانه**: زبان‌های اصلی **فارسی (fa)** و **انگلیسی (en)**، به‌همراه عربی، ترکی، روسی، چینی، اسپانیایی، فرانسه، آلمانی، هندی، اردو و آذری. پشتیبانی کامل RTL برای فارسی، عربی و اردو.
- **🛠️ پنل مدیریت**: فعال/غیرفعال کردن درگاه‌های پرداخت، مدیریت کاربران و نقش‌ها، ثبت نرخ محصولات و مشاهده گزارش‌های جامع فروش.
